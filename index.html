⚡ Auto Scanner Pro — Real M1

This Vercel project provides a server-side market-data proxy and a bookmarklet that calculates RSI, EMA9/21, FVG and liquidity-sweep conditions from real 1-minute candles.

Setup

  1. Create a Twelve Data API key.
  2. Deploy this project to Vercel.
  3. In Vercel → Project Settings → Environment Variables, add TWELVEDATA_API_KEY.
  4. Redeploy after saving the variable.
  5. Bookmark the page, then edit the bookmark URL and replace it with the complete code from bookmarklet.txt.
  6. Open your trading page and run the bookmark.
Important: Real market data does not mean guaranteed trade accuracy. The scanner is a decision-support tool. It does not click Up/Down or place trades automatically.

Bookmarklet

Open bookmarklet.txt and copy the entire single-line JavaScript into your bookmark URL.
